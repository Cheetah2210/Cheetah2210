# Cheetahs Creations - Emily 🌻 

Welcome to the open-source hardware 
engineering workspace for Cheetahs Creations.

>“Don't waste time or time will waste you."

## 🛠️ Focus Areas

* **Thermal Recovery Ecosystems:** Designing next-generation, solid-state 
  waste heat recovery retrofits for high-density 
  data centers.

* **Fluid Dynamics & MHD:** Engineering closed-loop magnetohydrodynamic 
  power channels and specialized immiscible 
  binary fluid suspensions.

* **Local Data Sovereignty:** Building high-redundancy, cloud-independent 
  monitoring systems utilizing Home Assistant 
  and local MQTT tracking networks.

## 🔬 Active Open-Source Ecosystem

* **Data-Center-Thermal-Scavenger:** External, decoupled thermal scavenging 
  retrofit converting waste heat into usable power.

* **The-Cascading-Solid-State-Thermal-Scavenger:** Solid-state core optimizing MHD channels and 
  multi-stage kinetic scavenging loops.

* **The-Cascading-Hybrid-Thermal-Scavenger:** Our comprehensive super project cascading an 
  MHD loop with a secondary refrigerant vapor cycle.
